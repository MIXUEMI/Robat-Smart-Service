🔄 请求处理流

一次用户对话的完整链路
Streamlit UI → HTTP → FastAPI /chat → Middleware Chain → ReAct Agent ⇄ Tools (8x) → SSE Stream

中间件在 Agent 执行前后插入：请求日志 → Agent 推理 → 工具调用 → 响应日志 → 流式返回

分层职责

前端层 Streamlit — 聊天 UI、流式渲染、对话历史展示、会话管理
API 层 FastAPI — REST + SSE 流式端点、请求验证、错误处理
中间件层 请求日志审计、全链路耗时监控、动态 Prompt 场景切换
Agent 层 ReAct Agent 引擎 — 推理循环、工具调度、对话记忆、流式输出
工具层 8 个 @tool 原子函数 — 每个独立、可测试、可组合
数据层 ChromaDB 向量库 + 文档分块 + 本地 Embedding
